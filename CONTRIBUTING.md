# Contributing

NoJobEngine is currently a personal engine-development project and learning platform.

Issues that reproduce a concrete engine/editor bug are welcome. When reporting a problem, please include:

- a short description of the issue;
- steps to reproduce it;
- the build configuration used;
- relevant console/compiler output;
- screenshots when the problem is visual.

For larger changes, opening an issue before a pull request is recommended so the scope can be discussed first.

Please keep changes focused and consistent with the existing C++20/CMake codebase.
